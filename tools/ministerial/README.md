# الأسئلة الوزارية — طريقة العمل

- `engine.js` + `engine.css`: المحرك (الزر، نافذة الأسئلة، التاگات، الإضاءة بالمحاكاة).
- `data/bio_chN.js`: أسئلة كل فصل، المفتاح = اسم ملف المحاكاة بدون `.html`.
- `build.js`: يفحص البيانات ثم يحقن المحرك وأسئلة كل محاكاة **داخل ملف المحاكاة نفسه**
  بين `<!--MOE-MIN:START-->` و `<!--MOE-MIN:END-->` (حتى تعمل بدون إنترنت بدون ملفات إضافية).

```
node tools/ministerial/build.js --check   # فحص فقط
node tools/ministerial/build.js           # فحص + حقن
```

قواعد الأمان:
1. إذا وُجد خطأ واحد في البيانات لا يُكتب أي ملف.
2. المحرك معزول بالكامل: أي خطأ فيه يخفي زر الوزاريات فقط والمحاكاة تبقى تعمل.
3. زر «شوف بالمحاكاة» يظهر فقط إذا المحاكاة عرّفت `window.MOE_SIM` (انظر endoplasmic_reticulum.html).
4. العمل على فرع `ministerial`، ولا يُدمج في `main` إلا بعد المراجعة.
